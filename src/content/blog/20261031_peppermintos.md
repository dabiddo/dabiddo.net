# Distro hopped to Peppermint OS
My old laptop is slowly diying so I bought a new laptop, took the time to distro hopped, my current laptop is running linux lite, but always curious to try Peppermint OS, its lighter, does not install a lot of bloatware and it still runs xfce.

Latest version is based on Debian 13 (trixie), so that is a plus.

# Domain migration
Currently I also migrated my domain registrar from Squarespace to Porkbun, is cheaper and with todays economy it justs makes sense.

I still have a lot of things to configure on this new laptop but the main apps I use all work.
